# Rotisserie Rhapsody

Build a premium, modern, mobile-first restaurant website for North Rotisserie, a rotisserie restaurant in La Marsa, Tunisia.

The goal is to create a website that feels like a real, established restaurant brand — not a generic AI-generated restaurant template. The design should be visually impressive enough that the owner immediately sees the value of having a professional website.

BRAND & VISUAL DIRECTION

Restaurant name: North Rotisserie

Location: 19 Rue Imam Abou Hanifa, La Marsa 2078, Tunisia

Phone: +216 26 164 204

Cuisine/concept: Rotisserie, grilled chicken, casual dining, takeaway.

Create a warm, sophisticated food-focused visual identity.

Design direction:

Premium but approachable

Modern Mediterranean / North African atmosphere

Strong food photography

Warm neutral tones

Elegant typography

Lots of whitespace

Subtle animations

Rounded cards and modern layouts

Avoid excessive gradients

Avoid the typical "AI SaaS" aesthetic

Avoid excessive glassmorphism

Do not make it look corporate

The food should be the visual focus

Use high-quality food imagery throughout the design. Prefer realistic grilled chicken, roasted chicken, crispy potatoes, fresh salads, sandwiches, and restaurant interior imagery.

HERO SECTION

Create a full-screen hero section with an impressive close-up image of rotisserie/grilled chicken.

Headline:

"Fire. Flavor. North."

Supporting text:

"Slow-roasted, freshly served, and made for good moments in La Marsa."

Primary CTA:
Explore the Menu

Secondary CTA:
Find Us

Add a small location indicator:
La Marsa, Tunis

The hero should immediately communicate that this is a food destination.

NAVIGATION

Sticky modern navbar.

Left:
NORTH ROTISSERIE

Navigation:

Home

Menu

About

Gallery

Location

Right:
Order / Contact

On mobile, use a polished hamburger menu.

MENU SECTION

Create a beautiful restaurant menu rather than a boring list.

Categories:

Rotisserie

Burgers & Sandwiches

Sides

Salads

Drinks

Use attractive cards with:

Food image

Item name

Short description

Price placeholder

IMPORTANT:
Do not invent exact prices if they are not provided.

Use clearly marked placeholder prices such as:
Price — Contact restaurant

Include several realistic example menu items based on the restaurant concept, but make it obvious in the code/content that these are placeholders to be replaced with the restaurant's actual menu.

Feature a large signature item section:

The North Chicken

with an impressive food image and a short description.

Add CTA:
See Full Menu

ABOUT SECTION

Create a strong editorial-style section explaining the restaurant.

Headline:

"Simple food. Done properly."

Copy should communicate:

quality ingredients

slow roasting

grilled flavors

generous portions

casual atmosphere

La Marsa location

Do NOT make unsupported claims such as awards, years in business, celebrity customers, or specific sourcing claims.

Keep the writing concise and believable.

FEATURE SECTION

Create a visually striking section highlighting the restaurant's core experience.

Three features:

Slow Roasted
Carefully cooked for deep flavor and tender meat.

Fresh & Generous
Comfort food made to be satisfying.

Made for La Marsa
A casual place to eat, share, and come back to.

Use icons or small illustrations, but keep them subtle.

GALLERY

Create an immersive image gallery.

Use:

Rotisserie chicken

Grilled food

Burgers/sandwiches

Side dishes

Restaurant atmosphere

Exterior/location

Use a modern masonry/grid layout.

Add subtle hover effects.

Add social media icons as placeholders if official social accounts have not been verified.

Do not invent social media usernames or URLs.

UX REQUIREMENTS

The website must be:

Fully responsive

Mobile-first

Fast loading

Accessible

SEO-friendly

Smooth scrolling

Keyboard accessible

Properly structured with semantic HTML

Add tasteful animations:

Fade/slide reveals

Image hover effects

Smooth navigation

Subtle button interactions

Animations must remain fast and professional.

SEO

Add appropriate:

Page title

Meta description

Open Graph metadata

Restaurant/local-business structured data where appropriate

Use the restaurant's real name, La Marsa location, and phone number.

IMPORTANT

This is a demo website for a real restaurant.

Do not fabricate:

Awards

Customer testimonials

Exact menu prices

Opening hours

Delivery partnerships

Social media accounts

Reservations systems

Claims about the restaurant's history

Where information is unknown, use placeholders that can easily be replaced later.

The final result should feel like a $1,000+ professionally designed restaurant website, while remaining clean, fast, and practical.

Prioritize visual impact, food photography, mobile experience, and clear conversion paths over unnecessary features.
